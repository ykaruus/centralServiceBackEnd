# CentralService

**CentralService** é um sistema de logística interna para equipes de suporte técnico.

A aplicação **central**iza o controle de envio, movimentação e histórico de equipamentos como notebooks, desktops e periféricos entre setores e unidades.

## Problema

Equipes de TI frequentemente controlam equipamentos utilizando planilhas ou mensagens informais, o que gera:

* perda de histórico de movimentações
* dificuldade de rastrear responsáveis
* equipamentos desaparecidos ou esquecidos
* baixa organização operacional

## Solução

O CentralService fornece um painel único onde é possível:

* registrar equipamentos
* acompanhar envios
* visualizar responsáveis atuais
* manter histórico completo de movimentação
* organizar logística entre departamentos

## Stack

* Go (Golang) — Backend API
* MongoDb
* REST API
* JWT Authentication + Google Auth 2.0

## Objetivo

O projeto foi desenvolvido com foco em ambientes corporativos onde há constante circulação de equipamentos entre setores.
